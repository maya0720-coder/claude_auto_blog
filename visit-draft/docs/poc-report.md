# 0단계 PoC 결과 보고서

> 상태: **미실행**. 실제 네이버 계정으로 `npm run poc`를 실행한 뒤 이 문서를 채운다.
> 결과 원본: `data/poc/result-*.json` (블로그 ID는 가려서 저장됨, Git 제외 대상)
> 이 문서에는 블로그 ID, 카테고리 이름, 글 제목, 스크린샷을 넣지 않는다.

## 실행 방법

- `visit-draft\run-app.cmd`를 더블클릭하면 브라우저에 화면이 열린다. 블로그 주소, 카테고리 번호(선택), 테스트용 사진 3장을 넣고 [테스트 시작]을 누른다. 업로드용 사본은 EXIF를 지운 뒤 올라간다.
- 명령줄로 실행하려면: `npm run poc -- --blog <본인 블로그 ID> --category <카테고리 번호> --images p1.jpg,p2.jpg,p3.jpg`
- 처음 실행하면 크롬 창이 따로 열린다. 네이버에 **직접** 로그인한다(최대 5분 대기).
- **세션 유지 확인(①):** 한 번 더 실행해 결과 화면에 "이전 로그인이 유지되어 있었습니다"(`hadSessionAtStart: true`)가 나오는지 본다.
- 실행 후 네이버 글쓰기 → "저장 글" 목록에서 글이 생겼는지, **발행되지 않았는지** 직접 확인한다. 확인이 끝나면 테스트 글을 지운다.
